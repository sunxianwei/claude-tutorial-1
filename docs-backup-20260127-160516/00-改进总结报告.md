### 问题 1：命令准确性（🔴 高优先级）

#### 1.1 `claude-code` vs `claude`

**影响范围：** 10+ 处

**位置：**
- `docs/README.md` - 快速开始部分
- 多个示例代码块

**修复方案：**
```bash
# 全局替换
find docs -name "*.md" -exec sed -i '' 's/claude-code/claude/g' {} \;
```

---

#### 1.2 `claude --show-rules` 不存在

**影响范围：** 3 处

**位置：**
- `docs/01-安装配置.md` 第 43 行
- `docs/02-规则文件系统.md` 第 392 行

**修复方案：** 删除或替换为正确的说明

---

#### 1.3 MCP 子命令不准确

**影响范围：** 10+ 处

**错误命令：**
- `claude mcp info` → 应该是 `claude mcp get`
- `claude mcp test` → 不存在
- `claude mcp update` → 不存在
- `claude mcp restart` → 不存在
- `claude mcp logs` → 不存在
- `claude mcp enable/disable` → 不存在

**正确的命令列表：**
```bash
claude mcp add
claude mcp add-from-claude-desktop
claude mcp add-json
claude mcp get
claude mcp list
claude mcp remove
claude mcp reset-project-choices
claude mcp serve
```

## 💡 对教程作者的建议

### 1. 建立命令验证流程

**建议建立自动化验证：**

```bash
#!/bin/bash
# validate-commands.sh

# 从文档中提取所有 claude 命令
grep -r "^claude " docs/ > commands.txt

# 逐个验证
while read cmd; do
  echo "Testing: $cmd"
  eval "$cmd --help" || echo "❌ Failed: $cmd"
done < commands.txt
```
