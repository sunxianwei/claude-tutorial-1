# 10 - 快捷键速查：高效操作

## Claude Code CLI 快捷命令

### 基础命令

```bash
# 查看帮助
claude --help

# 查看版本
claude --version

# 显示已加载的规则
claude --show-rules

# 显示已加载的 MCP 服务
claude --mcp-list

# 调试模式
claude --debug . "command"

# 干运行（不实际执行）
claude --dry-run . "command"
```

### 初始化和配置

```bash
# 初始化新项目

# 从模板初始化

# 指定 MCP 预设

# 生成规则模板
claude generate-template --type=rules
```

### 文件和代码操作

```bash
# 读取文件（显式）
claude read "src/index.ts"

# 查找文件
claude find --pattern="*.vue" --path="src/"

# 搜索代码
claude search "TODO" --type="typescript"

# 查看项目结构
claude tree --depth=2
```

### Git 操作

```bash
# 显示 git 状态
claude git status

# 显示最近提交
claude git log --oneline -10

# 显示 diff
claude git diff

# 自动提交（带 AI 生成的提交信息）
claude commit --auto
```

### 模型和参数

```bash
# 指定模型
claude --model="claude-opus-4-1-20250805" . "command"

# 指定温度
claude --temperature=0.5 . "command"

# 指定最大 tokens
claude --max-tokens=8000 . "command"

# 指定上下文窗口大小
claude --context-window=large . "command"
```

### SubAgent 相关

```bash
# 列出所有可用的 SubAgent
claude --list-agents

# 使用特定 SubAgent
claude --subagent=codegen . "command"

# 链式执行多个 agent
claude --subagent=codegen --chain="test,security,doc" . "command"

# 显示 SubAgent 详情
claude --agent-info=codegen
```

### MCP 相关

```bash
# 检查 MCP 连接
claude --mcp-check

# 显示 MCP 详情
claude --mcp-info

# 测试特定 MCP 服务
claude --test-mcp=postgres

# 重新加载 MCP 配置
claude --reload-mcp
```

## 常用工作流快速命令

### 新功能开发（完整流程）

```bash
#!/bin/bash
# dev-feature.sh

FEATURE=$1

# 1. 代码生成
claude --subagent=codegen . "实现 $FEATURE"

# 2. 生成测试
claude --subagent=testing . "为上面的代码生成单元测试"

# 3. 安全审查
claude --subagent=security . "审查安全性"

# 4. 代码审查
claude --subagent=review . "完整代码审查"

# 5. 生成文档
claude --subagent=documentation . "生成 API 文档"

# 6. 提交
claude commit --auto
```

使用：

```bash
chmod +x dev-feature.sh
./dev-feature.sh "用户认证功能"
```

### Bug 修复工作流

```bash
#!/bin/bash
# fix-bug.sh

BUG_DESC=$1

# 1. 定位 bug
claude search "$BUG_DESC"

# 2. 分析代码
claude read "path/to/buggy/file.ts"

# 3. 修复
claude --subagent=refactor . "修复: $BUG_DESC"

# 4. 生成测试
claude --subagent=testing . "为 bug 修复生成回归测试"

# 5. 验证
echo "运行所有测试..."
npm test

# 6. 提交
claude commit --auto
```

### 性能优化工作流

```bash
#!/bin/bash
# optimize.sh

# 1. 分析性能
claude --subagent=refactor . "分析性能瓶颈"

# 2. 优化
claude --subagent=refactor . "优化性能"

# 3. 测试
npm run test:performance

# 4. 对比
claude . "对比优化前后的性能数据"

# 5. 提交
claude commit --auto
```

### 代码审查工作流

```bash
#!/bin/bash
# code-review.sh

BRANCH=$1

# 1. 获取 diff
claude git diff main..$BRANCH

# 2. 执行完整审查
claude --subagent=review . "审查 $BRANCH 分支的所有变更"

# 3. 检查测试
npm test

# 4. 检查 coverage
npm run test:coverage

# 5. 生成审查报告
claude . "生成详细的代码审查报告"
```

### 项目迁移工作流

```bash
#!/bin/bash
# migrate-project.sh

OLD_TECH=$1
NEW_TECH=$2

# 1. 分析当前项目
claude . "分析项目中 $OLD_TECH 的使用情况"

# 2. 生成迁移计划
claude . "生成从 $OLD_TECH 迁移到 $NEW_TECH 的详细计划"

# 3. 分步实施
claude --subagent=refactor . "执行迁移计划的第一步"

# 4. 测试验证
npm test

# 5. 重复第 3-4 步，直到完成
```

## 自定义快捷命令

在 `.claude/shortcuts.json` 中定义：

```json
{
  "commands": {
    "dev": "npm run dev",
    "test": "npm test && npm run coverage",
    "build": "npm run clean && npm run build",
    "deploy": "npm run build && npm run deploy:prod",
    "pr": "git push origin HEAD && gh pr create",
    "feature": "./scripts/dev-feature.sh",
    "hotfix": "./scripts/fix-bug.sh"
  }
}
```

使用：

```bash
claude . --run-shortcut=dev
claude . --run-shortcut=test
claude . --run-shortcut=deploy
```

## 高级技巧

### 1. 管道组合

```bash
# 搜索 → 分析 → 优化 → 测试
claude search "N+1 query" \
  && claude --subagent=refactor . "优化查询" \
  && npm test
```

### 2. 条件执行

```bash
# 如果测试通过，则提交
npm test && claude commit --auto
```

### 3. 并行执行

```bash
# 同时运行多个 agent
claude --subagent=codegen . "task1" &
claude --subagent=testing . "task2" &
wait
```

### 4. 环境变量控制

```bash
# 使用不同的 MCP 配置
MCP_PRESET=development claude . "command"
MCP_PRESET=production claude . "command"
```
