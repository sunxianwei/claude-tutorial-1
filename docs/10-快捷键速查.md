# 10 - 快捷键速查：高效操作

> 💡 **提示：** 在交互式会话中按 `?` 查看当前环境可用的所有快捷键

## 🎯 Claude Code 内置快捷键（交互式会话）

### 通用控制快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `?` | 显示帮助 | 查看当前环境可用的所有快捷键 |
| `Ctrl+C` | 取消操作 | 取消当前输入或停止生成 |
| `Ctrl+D` | 退出会话 | 结束 Claude Code 交互式会话 |
| `Ctrl+G` | 打开编辑器 | 在默认文本编辑器中编辑提示词 |
| `Ctrl+L` | 清屏 | 清除终端屏幕（保留对话历史） |
| `Ctrl+O` | 切换详细输出 | 显示/隐藏工具使用的详细信息 |
| `Ctrl+R` | 反向搜索 | 搜索命令历史（交互式搜索） |
| `Ctrl+B` | 后台任务 | 将运行中的 Bash 命令或 Agent 移到后台（Tmux 用户需按两次） |
| `Esc` `Esc` | 回退对话 | 撤销最近的代码更改/对话 |

### 导航快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `↑` / `↓` | 历史导航 | 浏览命令历史（上一条/下一条） |
| `←` / `→` | 切换标签页 | 在对话标签页之间循环切换 |
| `Home` | 行首 | 光标移动到行首 |
| `End` | 行尾 | 光标移动到行尾 |

### 图片和剪贴板

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+V` (Windows/Linux) | 粘贴图片 | 从剪贴板粘贴图片 |
| `Cmd+V` (macOS/iTerm2) | 粘贴图片 | 从剪贴板粘贴图片 |
| `Alt+V` (Windows) | 粘贴图片 | 从剪贴板粘贴图片（备选） |

### macOS 增强快捷键

> ⚠️ **配置要求：** 需要将 Option 键设置为 Meta 键

| 快捷键 | 功能 | 配置方法 |
|--------|------|---------|
| `Alt+B` | 后退一个单词 | 见下方配置说明 |
| `Alt+F` | 前进一个单词 | 见下方配置说明 |
| `Alt+Y` | - | 见下方配置说明 |
| `Alt+M` | - | 见下方配置说明 |
| `Alt+P` | - | 见下方配置说明 |

#### macOS 终端配置

**iTerm2：**
```
Settings → Profiles → Keys → Left Option Key: "Esc+"
Settings → Profiles → Keys → Right Option Key: "Esc+"
```

**Terminal.app：**
```
Settings → Profiles → Keyboard → ✓ "Use Option as Meta Key"
```

**VS Code 终端：**
```
Settings → Profiles → Keys → Left Option Key: "Esc+"
Settings → Profiles → Keys → Right Option Key: "Esc+"
```

## 🎨 自定义快捷键（v2.1.18+）

从 v2.1.18 版本开始，Claude Code 支持自定义键盘快捷键。

### 打开配置文件

在交互式会话中输入：
```
/keybindings
```

或直接编辑：
```bash
~/.claude/keybindings.json
```

### 配置文件格式

```json
{
  "bindings": [
    {
      "context": "default",
      "keys": {
        "Ctrl+Shift+C": "copy-code",
        "Ctrl+Shift+V": "paste-code",
        "Ctrl+Shift+F": "format-code"
      }
    },
    {
      "context": "editing",
      "keys": {
        "Ctrl+S": "save-and-continue",
        "Ctrl+Q": "cancel-edit"
      }
    }
  ]
}
```

### 可用上下文

- `default` - 默认上下文
- `editing` - 编辑模式
- `dialog` - 对话框中
- `selection` - 有选中内容时

### 快捷键序列（Chord）

支持多键组合：
```json
{
  "keys": {
    "Ctrl+K Ctrl+C": "toggle-comments",
    "Ctrl+K Ctrl+U": "uncomment"
  }
}
```

## Claude Code CLI 常用命令

### 基础命令

```bash
# 查看帮助
claude --help
claude -h

# 查看版本
claude --version
claude -v

# 启动交互式会话（当前目录）
claude .

# 调试模式
claude --debug .
claude -d .

# 详细输出
claude --verbose .
```

### 会话管理

```bash
# 继续最近的会话
claude --continue
claude -c

# 恢复指定会话
claude --resume <session-id>
claude -r <session-id>

# 恢复会话（交互式选择）
claude -r

# 分叉会话（创建新分支）
claude --fork-session --resume <session-id>

# 指定会话ID
claude --session-id <uuid> .

# 禁用会话持久化
claude --no-session-persistence -p .
```

### MCP 管理

```bash
# 列出 MCP 服务器
claude mcp list

# 添加 MCP 服务器
claude mcp add <name> -- <command>

# 示例：添加文件系统 MCP
claude mcp add filesystem -- npx @modelcontextprotocol/server-filesystem .

# 删除 MCP 服务器
claude mcp remove <name>

# 查看 MCP 详情
claude mcp info <name>

# 测试 MCP 连接
claude mcp test <name>
```

### 模型和 Agent

```bash
# 指定模型（使用别名）
claude --model sonnet .
claude --model opus .

# 指定完整模型名
claude --model "claude-sonnet-4-5-20250929" .

# 指定 Agent
claude --agent <agent-name> .

# 自定义 Agents（JSON）
claude --agents '{"reviewer": {"description": "Code reviewer", "prompt": "You are a code reviewer"}}' .
```

### 非交互模式（--print）

```bash
# 打印输出并退出
claude --print . "你的提示词"
claude -p . "你的提示词"

# 指定输出格式
claude -p --output-format text . "提示词"
claude -p --output-format json . "提示词"
claude -p --output-format stream-json . "提示词"

# JSON Schema 结构化输出
claude -p --json-schema '{"type":"object","properties":{"name":{"type":"string"}}}' . "提示词"

# 流式输入
claude -p --input-format stream-json . "提示词"

# 包含部分消息
claude -p --include-partial-messages . "提示词"
```

### 权限和工具控制

```bash
# 指定允许的工具
claude --allowed-tools "Bash,Edit,Read" .

# 指定禁止的工具
claude --disallowed-tools "Bash" .

# 禁用所有工具
claude --tools "" .

# 使用默认工具
claude --tools "default" .

# 设置权限模式
claude --permission-mode default .
claude --permission-mode acceptEdits .
claude --permission-mode dontAsk .
claude --permission-mode bypassPermissions .
claude --permission-mode plan .
claude --permission-mode delegate .

# 允许跳过权限（作为选项）
claude --allow-dangerously-skip-permissions .

# 跳过所有权限检查（仅用于沙箱）
claude --dangerously-skip-permissions .
```

### MCP 配置

```bash
# 加载 MCP 配置文件
claude --mcp-config <file.json> .

# 加载多个 MCP 配置
claude --mcp-config <file1.json> <file2.json> .

# 仅使用指定的 MCP 配置
claude --strict-mcp-config --mcp-config <file.json> .
```

### 高级选项

```bash
# 加载自定义设置
claude --settings <file-or-json> .

# 指定设置来源
claude --setting-sources user,project,local .

# 添加额外目录
claude --add-dir <dir1> <dir2> .

# Chrome 集成
claude --chrome .
claude --no-chrome .

# IDE 集成（自动连接）
claude --ide .

# 加载插件目录
claude --plugin-dir <path> .

# 禁用斜杠命令（Skills）
claude --disable-slash-commands .
```

### API 特定选项（API Key 用户）

```bash
# Beta 功能
claude --betas <beta1> <beta2> . "提示词"

# 回退模型
claude -p --fallback-model <model> . "提示词"

# 预算限制
claude -p --max-budget-usd <amount> . "提示词"
```

### 系统提示词

```bash
# 自定义系统提示词
claude --system-prompt "你是一个 Python 专家" .

# 追加系统提示词
claude --append-system-prompt "使用 Python 3.11+" .
```

### 调试选项

```bash
# 启用调试
claude --debug .
claude -d .

# 过滤调试类别
claude --debug api,hooks .
claude -d "!statsig,!file" .

# MCP 调试（已废弃，使用 --debug）
# claude --mcp-debug .
```

## 🔄 后台任务详解（Ctrl+B）

### 什么是后台任务？

使用 `Ctrl+B` 可以将正在运行的 Bash 命令或 Agent 移到后台，让你在等待长时间运行的进程时继续与 Claude 交互。

### 工作原理

1. **异步执行**：命令在后台异步运行
2. **立即返回**：返回一个后台任务 ID
3. **继续工作**：可以立即输入新的提示
4. **输出缓冲**：输出被缓冲，Claude 可以使用 TaskOutput 工具检索

### 使用方法

#### 方法1：提示 Claude 后台运行
```bash
# 在对话中说：
"在后台运行 npm run build"
"后台启动开发服务器"
```

#### 方法2：手动按 Ctrl+B
```bash
# 当 Claude 正在运行命令时，按 Ctrl+B
# 命令会立即移到后台
```

#### 方法3：使用 ! 前缀 + Ctrl+B
```bash
# 输入：
!npm run dev

# 然后按 Ctrl+B 将其后台运行
```

### 查看和管理后台任务

```bash
# 在会话中输入：
/tasks                 # 查看所有后台任务
/tasks status          # 查看任务状态
```

或直接问 Claude：
```
"显示所有后台任务"
"清除所有任务"
"检查任务 #123 的输出"
```

### 常用场景

| 场景 | 示例命令 | 说明 |
|------|---------|------|
| **构建工具** | `npm run build`, `webpack` | 构建可能需要几分钟 |
| **开发服务器** | `npm run dev`, `vite` | 长时间运行的服务 |
| **测试运行** | `npm test`, `pytest` | 大型测试套件 |
| **包管理** | `npm install`, `yarn` | 安装大量依赖 |
| **容器操作** | `docker build`, `docker-compose up` | Docker 操作 |
| **基础设施** | `terraform apply`, `ansible-playbook` | 云资源部署 |

### 实用示例

```bash
# 示例1：后台构建，继续开发
"在后台运行 npm run build，然后帮我优化 src/utils.ts"

# 示例2：启动服务，等待就绪
"后台启动 npm run dev，等它启动后告诉我"

# 示例3：运行测试，继续编码
"后台运行所有测试，同时我们来实现登录功能"
```

### 特殊说明

#### Tmux 用户
> ⚠️ **重要：** Tmux 使用 `Ctrl+B` 作为前缀键，所以需要按**两次**：
> 1. 第一次 `Ctrl+B` - Tmux 前缀
> 2. 第二次 `Ctrl+B` - Claude Code 后台任务

#### 禁用后台任务

如果不需要此功能，可以禁用：

```bash
# 在 ~/.bashrc 或 ~/.zshrc 中添加：
export CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1
```

### 任务持久化

```bash
# 跨会话共享任务列表
export CLAUDE_CODE_TASK_LIST_ID=my-project
claude .

# 任务将保存在 ~/.claude/tasks/my-project/
```

### 快捷键组合

```bash
# Ctrl+B + /tasks 的组合使用：
1. 按 Ctrl+B 后台化当前任务
2. 输入 /tasks 查看所有任务
3. 继续其他工作
```

## 📝 斜杠命令（Slash Commands）

在交互式会话中，可以使用斜杠命令快速执行操作：

| 命令 | 功能 | 示例 |
|------|------|------|
| `/tasks` | 查看后台任务 | 列出和管理后台任务 |
| `/keybindings` | 打开快捷键配置 | 自定义键盘快捷键 |
| `/help` | 显示帮助 | 查看可用命令 |
| `/clear` | 清空对话 | 开始新的对话 |
| `/exit` | 退出会话 | 等同于 `Ctrl+D` |

> 💡 使用 `--disable-slash-commands` 可以禁用所有斜杠命令

## 💡 实用技巧

### 快速启动

```bash
# 直接提问（非交互模式）
claude -p . "解释这段代码的功能"

# 继续上次的对话
claude -c

# 调试模式查看详细信息
claude --debug .
```

### 组合命令示例

```bash
# 使用特定模型
claude --model opus .

# 指定 Agent + 打印模式
claude --agent reviewer -p . "审查 src/ 目录的代码"

# 自定义权限 + MCP配置
claude --permission-mode dontAsk --mcp-config .claude/mcp.json .

# 禁用部分工具
claude --disallowed-tools "Bash" --allowed-tools "Edit,Read" .

# JSON 输出 + 结构化数据
claude -p --output-format json --json-schema '{"type":"object"}' . "提取用户信息"
```

### MCP 快速配置

```bash
# 添加常用 MCP 服务器
claude mcp add filesystem -- npx @modelcontextprotocol/server-filesystem .
claude mcp add git -- npx @modelcontextprotocol/server-git --repository .
claude mcp add postgres -- npx @modelcontextprotocol/server-postgres

# 查看所有 MCP
claude mcp list

# 测试 MCP 连接
claude mcp test filesystem
```

## 🚀 效率提升技巧

### 1. 快速查看帮助

```bash
# 在会话中按 ? 查看所有快捷键
?

# 查看命令行选项
claude --help
```

### 2. 组合快捷键使用

```bash
# 先清屏（Ctrl+L），再搜索历史（Ctrl+R）
# 后台任务（Ctrl+B），再打开编辑器（Ctrl+G）
```

### 3. 自定义常用操作

在 `~/.claude/keybindings.json` 中：
```json
{
  "bindings": [
    {
      "context": "default",
      "keys": {
        "Ctrl+Shift+T": "run-tests",
        "Ctrl+Shift+D": "debug-code",
        "Ctrl+Shift+R": "refactor-selection"
      }
    }
  ]
}
```

### 4. Shell 别名

在 `~/.bashrc` 或 `~/.zshrc` 中：
```bash
# 快速启动
alias cc='claude .'
alias ccp='claude -p .'
alias ccc='claude -c'

# 常用操作
alias cctest='claude -p . "运行所有测试并报告结果"'
alias ccreview='claude --agent reviewer .'
```

## ⚠️ 重要提醒

1. **查看实时帮助**
   - 在会话中按 `?` 查看当前环境的快捷键
   - 不同终端可能有差异

2. **平台差异**
   - macOS 需要配置 Option 键为 Meta
   - Windows/Linux 某些快捷键可能不同
   - WSL 用户需要检查终端设置

3. **版本要求**
   - 自定义快捷键需要 v2.1.18+
   - 某些功能需要最新版本
   - 执行 `claude --version` 检查版本

4. **终端兼容性**
   - iTerm2、Terminal.app、Alacritty、Kitty 等都支持
   - VS Code 集成终端需要特殊配置
   - 某些快捷键可能与终端快捷键冲突
