### 必读章节 🔴

#### 3. [安装配置](01-安装配置.md)
**时间：** 10 分钟 | **难度：** ⭐

**实践任务：**
```bash
# 1. 安装
npm install -g @anthropic-ai/claude-code

# 2. 配置 API Key
export ANTHROPIC_API_KEY="your-key"

# 3. 初始化项目
cd your-project

# 4. 验证
claude --version
```

**常见问题：**
- API 密钥无效 → 检查是否正确复制
- 命令找不到 → 检查 npm 全局 bin 路径
- 配置不生效 → 检查环境变量是否加载

---

#### 4. [规则文件系统](02-规则文件系统.md)
**时间：** 20 分钟 | **难度：** ⭐⭐

**实践任务：**

创建项目的 `CLAUDE.md`：

```markdown
# 项目规范

## 技术栈
- 语言：TypeScript
- 框架：React 18
- 状态管理：Zustand
- 样式：Tailwind CSS

## 代码风格
- 使用函数式组件
- 使用 TypeScript 严格模式
- 2 空格缩进
- 单引号

## 提交规范
- 使用 Conventional Commits
- 中文提交信息
```

**学习检验：**
- 能否独立编写一个 30 行的规则文件？
- 规则文件是否让 Claude 生成的代码符合项目规范？

## 💡 常见问题

### Q1：我需要学习所有章节吗？
**A：** 不需要。必读章节（🔴）是核心内容，推荐阅读（🟢）可根据需要选择。

### Q2：学习基础篇需要多长时间？
**A：** 阅读约 90 分钟，实践约 5-10 小时。建议分 1-2 周完成。

### Q3：基础篇学完能做什么？
**A：** 能够使用 Claude Code 完成日常开发任务，工作效率提升 30-50%。

### Q4：什么时候应该学习进阶篇？
**A：** 当你：
- 熟练使用基础功能（使用 1 个月以上）
- 需要更强大的功能（MCP、SubAgents）
- 想要深度优化工作流
- 需要团队协作和规范

### Q5：遇到问题怎么办？
**A：** 
1. 查看对应章节的"常见问题"部分
2. 使用 `/help` 命令查看帮助
3. 查阅 [内置工具列表](03-内置工具列表.md)
4. 在 GitHub Discussions 提问
