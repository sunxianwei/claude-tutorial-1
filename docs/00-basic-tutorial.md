#### 3. [安装配置](02-installation.md)
**时间：** 10 分钟 | **难度：** ⭐

**内容概要：**
- API 密钥配置
- 项目初始化
- 配置文件详解
- 常见问题排查

**为什么重要：** 正确配置是使用的基础。

**实践任务：**
```bash
# 1. 安装
npm install -g @anthropic-ai/claude-code

# 2. 配置 API Key
export ANTHROPIC_API_KEY="your-key"

# 3. 初始化项目
cd your-project
claude init

# 4. 验证
claude --version
```

**常见问题：**
- API 密钥无效 → 检查是否正确复制
- 命令找不到 → 检查 npm 全局 bin 路径
- 配置不生效 → 检查环境变量是否加载

#### 4. [规则文件系统](06-rules-file.md)
**时间：** 20 分钟 | **难度：** ⭐⭐

**内容概要：**
- CLAUDE.md 文件的作用
- 如何编写规则文件

**为什么重要：** 规则文件是 Claude Code 最强大的功能，让 AI 理解你的项目规范。

**实践任务：**

```markdown

## 技术栈
- 语言：TypeScript
- 框架：React 18
- 状态管理：Zustand
- 样式：Tailwind CSS

## 代码风格
- 使用函数式组件
- 使用 TypeScript 严格模式
- 2 空格缩进
- 单引号

## 提交规范
- 使用 Conventional Commits
- 中文提交信息
```

**学习检验：**
- 能否独立编写一个 30 行的规则文件？
- 规则文件是否让 Claude 生成的代码符合项目规范？

## 🚀 学习建议

### 第 1 天：快速上手
1. 阅读 [重要说明](14-important-notice.md)（10 分钟）

3. 阅读 [安装配置](02-installation.md)（10 分钟）
4. 完成安装和配置（10 分钟）

**总计时间：** 35 分钟
**学习成果：** Claude Code 已安装并可用

### 第 2-3 天：理解规则
1. 阅读 [规则文件系统](06-rules-file.md)（20 分钟）
2. 为你的项目创建 CLAUDE.md（30 分钟）
3. 测试规则是否生效（10 分钟）

**总计时间：** 60 分钟
**学习成果：** 理解规则文件，能编写基础规则

### 第 4-7 天：实战练习
1. 阅读 [新项目工作流](11-new-project-workflow.md)（20 分钟）
2. 用 Claude Code 完成一个小项目（2-4 小时）
3. 遇到问题查阅 [内置工具列表](08-builtin-tools.md)

**总计时间：** 3-5 小时
**学习成果：** 能独立使用 Claude Code 开发

### 第 2-4 周：熟练应用
- 每天使用 Claude Code 完成实际工作
- 参考 [快捷键速查](10-shortcuts.md) 提高效率

### Q1：我需要学习所有章节吗？

### Q2：学习基础篇需要多长时间？
**A：** 阅读约 90 分钟，实践约 5-10 小时。建议分 1-2 周完成。

### Q3：基础篇学完能做什么？
**A：** 能够使用 Claude Code 完成日常开发任务，工作效率提升 30-50%。

### Q4：什么时候应该学习进阶篇？
**A：** 当你：
- 熟练使用基础功能（使用 1 个月以上）
- 需要更强大的功能（MCP、SubAgents）

### Q5：遇到问题怎么办？
**A：** 
1. 查看对应章节的"常见问题"部分
