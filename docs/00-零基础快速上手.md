# 零基础快速上手指南（30 分钟版）

> **适合人群：** 第一次使用 Claude Code 的初学者  
> **前置要求：** 会用终端，有 API Key  
> **预计时间：** 30 分钟  
> **版本要求：** Claude Code 2.1+

---

## 📋 准备工作（5 分钟）

### 第 1 步：确认已安装 Claude Code

打开终端，输入：

```bash
claude --version
```

**期望输出：**
```
2.1.5 (Claude Code)
```

✅ **如果看到版本号，说明已安装成功！**

❌ **如果报错 `command not found`：**
- macOS: 需要先安装 Claude Desktop 应用
- 安装后重启终端
- 参考官方文档：https://docs.anthropic.com

---

### 第 2 步：配置 API Key

```bash
# macOS/Linux 用户
export ANTHROPIC_API_KEY="sk-ant-你的密钥"

# 验证是否配置成功
echo $ANTHROPIC_API_KEY
```

**期望输出：**
```
sk-ant-你的密钥
```

💡 **提示：** 如果想永久保存，执行：
```bash
echo 'export ANTHROPIC_API_KEY="sk-ant-你的密钥"' >> ~/.zshrc
source ~/.zshrc
```

---

### 第 3 步：创建测试目录

```bash
# 创建一个干净的测试目录
mkdir ~/claude-test
cd ~/claude-test

# 验证当前位置
pwd
```

**期望输出：**
```
/Users/你的用户名/claude-test
```

---

## 🚀 第一次使用（10 分钟）

### 第 4 步：启动 Claude Code

```bash
claude .
```

**期望看到：**
```
Claude Code 2.1.5

> 
```

✅ **看到 `>` 提示符，说明启动成功！**

---

### 第 5 步：第一次对话

在 `>` 提示符后输入：

```
你好，请自我介绍一下
```

按 **Enter**

**期望看到：**
- Claude 开始回复
- 文字逐字显示
- 回复完成后返回 `>` 提示符

✅ **如果看到回复，恭喜！你已经成功运行了 Claude Code！**

---

### 第 6 步：让 Claude 创建文件

输入：

```
创建一个 hello.txt 文件，内容是"Hello, Claude Code!"
```

**会看到：**
1. Claude 询问：`Write file hello.txt? (y/n)`
2. 输入 `y` 并按 Enter
3. Claude 确认：`✓ Wrote hello.txt`

**验证结果：**
```bash
# 退出 Claude（输入 exit 或按 Ctrl+D）
exit

# 查看文件是否创建
cat hello.txt
```

**期望输出：**
```
Hello, Claude Code!
```

✅ **文件创建成功！**

## 💡 实用场景演练（10 分钟）

### 场景 1：代码生成

```bash
# 重新启动 Claude
claude .
```

输入：

```
用 Python 写一个函数，计算两个数的最大公约数，并包含测试代码
```

**Claude 会：**
1. 生成 Python 代码
2. 询问是否创建文件
3. 运行测试验证正确性

---

### 场景 2：代码解释

创建一个复杂文件：

```bash
# 退出 Claude
exit

# 创建一个示例文件
cat > example.js << 'EOF'
const users = [{id:1,name:"Alice"},{id:2,name:"Bob"}];
const result = users.reduce((acc,u)=>({...acc,[u.id]:u}),{});
console.log(result);
EOF
```

重新启动并询问：

```bash
claude .
```

输入：

```
解释 example.js 这段代码的作用，用通俗的语言
```

**Claude 会：**
- 读取文件
- 逐行解释代码
- 用简单的语言说明功能

---

### 场景 3：Bug 修复

创建有 bug 的代码：

```bash
exit

cat > buggy.py << 'EOF'
def divide(a, b):
    return a / b

print(divide(10, 0))
EOF
```

启动并修复：

```bash
claude .
```

输入：

```
修复 buggy.py 中的错误，添加异常处理
```

**Claude 会：**
- 发现除零错误
- 建议添加 try-except
- 修改文件

## 🎯 常用快捷操作

输出会直接显示在终端，然后退出。

```bash
claude --continue

```

```bash

```

## ⚠️ 常见问题和解决

### 问题 1：`command not found: claude`

**原因：** 未安装或未添加到 PATH

**解决：**
1. 确认已安装 Claude Desktop
2. 重启终端
3. 如果还不行，检查 PATH：
   ```bash
   echo $PATH | grep -i claude
   ```

---

### 问题 2：`API key not configured`

**原因：** API Key 未配置或配置错误

**解决：**
```bash
# 检查当前配置
echo $ANTHROPIC_API_KEY

# 如果为空，重新配置
export ANTHROPIC_API_KEY="你的密钥"
```

---

### 问题 3：Claude 一直没反应

**可能原因：**
1. 网络问题
2. API 限流
3. 服务器过载

**解决：**
1. 按 `Ctrl+C` 终止
2. 等待几秒后重试
3. 检查网络连接：
   ```bash
   curl -I https://api.anthropic.com
   ```

---

### 问题 4：Claude 创建了我不想要的文件

**解决：**
1. Claude 创建文件前会询问，仔细看提示
2. 如果已经创建，直接删除：
   ```bash
   rm 不想要的文件.txt
   ```
3. 在对话中说：
   ```
   撤销刚才的操作，删除 xxx 文件
   ```

## 💬 学习建议

### ✅ 推荐的学习方式

1. **每天用一用** - 把 Claude 当成日常工具
2. **从小任务开始** - 生成配置文件、写注释、解释代码
3. **逐步增加难度** - 小功能 → 完整模块 → 复杂项目
4. **记录遇到的问题** - 积累经验

### ❌ 不推荐的方式

1. ❌ 一次学完所有功能 - 容易混淆
2. ❌ 上来就做复杂项目 - 容易受挫
3. ❌ 完全依赖 Claude - 要保持判断力
4. ❌ 不看生成的代码 - 盲目信任有风险

---

### 使用 Claude 的正确姿势

**把 Claude 当成：**
- ✅ 有经验的同事 - 可以讨论方案
- ✅ 快速原型工具 - 快速验证想法
- ✅ 代码审查助手 - 发现潜在问题

**不要把 Claude 当成：**
- ❌ 完美的专家 - 可能有错误
- ❌ 生产代码生成器 - 需要人工审查
- ❌ 数据库 - 不要让它记住敏感信息
