## 🛠️ 快速安装

```bash
# 1. 安装 Claude Code
npm install -g @anthropic-ai/claude-code

# 2. 验证版本（应该是 2.1.x 或更高）
claude --version

# 3. 配置 API Key
export ANTHROPIC_API_KEY="sk-ant-xxxxxxxxxxxx"

# 4. 初始化项目
cd your-project

# 5. 启动使用
claude .
```

**获取 API Key：** https://console.anthropic.com
